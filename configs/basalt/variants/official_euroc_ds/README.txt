official_euroc_ds calibration variant
======================================

Generated by scripts/euroc_official_to_ds_calib.py:

  python scripts/euroc_official_to_ds_calib.py \
    --cam0-sensor-yaml E:/datasets/euroc_mav/all11/MH_01_easy/mav0/cam0/sensor.yaml \
    --cam1-sensor-yaml E:/datasets/euroc_mav/all11/MH_01_easy/mav0/cam1/sensor.yaml \
    --base-calib benchmarks/basalt/release_inputs/euroc_ds_calib.json \
    --out configs/basalt/variants/official_euroc_ds/euroc_ds_calib.json \
    --radius-quantile 0.9 --max-residual-px 0.3

CAVEAT (owner decision, recorded verbatim, 2026-09-15):

  Decision: option (b) -- use the inner-90%-radius fit (cam0 RMS 0.222 px /
  max 0.397 px; cam1 RMS 0.211 px / max 0.377 px). Rationale: that region
  covers essentially all pixels where FAST corners are detected, the
  residual is below Basalt's own observation std (vio_obs_std_dev ~= 0.5
  px), and the corner residuals come from extrapolating EuRoC's
  2-coefficient radtan beyond where it was ever calibrated -- they are not
  information we want to reproduce. xi~=0 is fine: we are reproducing the
  official model, not Basalt's DS shape.

What this means concretely: the Double Sphere intrinsics (fx, fy, cx, cy,
xi, alpha) were fit by nonlinear least squares to EuRoC's official
pinhole-radtan model (mav0/cam{0,1}/sensor.yaml), restricted to pixels
whose undistorted bearing radius falls in the inner 90% quantile of the
752x480 image (i.e. excluding the outer ~10% radius nearest the four
literal image corners). Both cameras' xi converged to ~0 (a degenerate
near-pinhole Double Sphere), which is expected and accepted per the
decision above -- this variant intentionally reproduces the *official*
factory pinhole-radtan calibration, not Basalt's own image-based DS
recalibration (which has xi=-0.24 cam0 / -0.21 cam1).

T_imu_cam is taken directly from the official T_BS matrices (body<-sensor,
the same direction as Basalt's IMU<-cam convention; verified by comparing
against the existing release calibration's cam0 entry, which is close but
not identical, as expected for two independent calibration procedures on
the same physical rig). Implied stereo baseline: 0.110078 m (matches the
official EuRoC factory baseline of ~0.11008 m almost exactly).

IMU noise/bias fields, calib_accel_bias/calib_gyro_bias, imu_update_rate,
vignette, T_mocap_world/T_imu_marker, mocap/cam time offsets are all
unchanged from benchmarks/basalt/release_inputs/euroc_ds_calib.json.
